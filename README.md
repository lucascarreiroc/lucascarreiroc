## 🏦 Projeto em destaque: Mini Banco API

API REST de carteira digital **em produção**, com Java 21 e Spring Boot 3.

- Transferências atômicas com `@Transactional` e controle de concorrência com lock otimista (`@Version`)
- Autenticação stateless com Spring Security + JWT e autorização por dono da conta
- 32 testes automatizados (JUnit 5, Mockito e Testcontainers com PostgreSQL real), incluindo teste de rollback
- CI com GitHub Actions e deploy com Docker no Render (banco no Neon)

🔗 [Repositório](https://github.com/lucascarreiroc/mini-banco-api) · 🌐 [API no ar (Swagger)](https://mini-banco-api-h5fc.onrender.com)
